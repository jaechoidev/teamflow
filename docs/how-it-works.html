teamflow

How teamflow works

Your agent session becomes the Delegator. It plans with you, then hands tasks to worker agents from any vendor. Each worker runs in its own tmux window, and every task and result passes through files in the repo's git directory.

  • your agent session
  • the mailbox in .git/teamflow/
  • worker windows in tmux

Where everything runs

Three places, and only files move between them, plus one short line typed into a worker's window.

The life of a task

A task's status lives in its mailbox record, so the Delegator never has to read a worker's screen to know where things stand.

What lives where

teamflow installs once per machine. A project keeps a few small files and borrows the rest from the installed version.

When you close your agent

A watcher in the background of the tmux server notices when the Delegator's session ends, so workers don't keep running for long.
